├── crud.html                       ← PARTE C: aplicación CRUD web (JavaScript)

├── empleados.json                  ← PARTE B: archivo JSON de empleados

2. Página web "Exportación Oro Verde - Finca La Sonora"

  1. Paso 1 Se creó index.html con 6 secciones: barra de navegación fija, portada (header) con imagen de fondo (la del paisaje antioqueño), sección Nosotros, tarjetas de estadísticas, sección Servicios, Galería y una sección de Contacto con formulario.
  2. Paso 2 El logo del sitio usa la imagen con los aguacates verdes (foto de la banda transportadora: aguacates cosechados.jpg) recortada en círculo con borde dorado.
  3. Paso 3 Todo el estilo se hizo con CSS moderno dentro del mismo HTML (variables :root, grid con repeat(auto-fit, minmax(...)), hover con transiciones). Así el sitio responde bien en pantalla pequeña o grande.
  4. Paso 4 En la barra de navegación hay un enlace "App Empleados" que lleva al módulo CRUD (Parte C).

3. PARTE B — Archivos empleados.xml y empleados.json

  1. Paso 1 Se definió la estructura de los 7 campos exigidos por la guía: IdEmpleado (int identity), strNombre (string 50), NumDocumento (long/bigint), strDireccion (string 50), strTelefono (string 50), strEmail (string 50), dtmIngreso (datetime).
  2. Paso 2 Se creó manualmente empleados.xml: elemento raíz <Empleados> y 5 registros hijos <Empleado> con coherencia realista (nombres antioqueños, direcciones de Medellín, Rionegro, Urrao, Sopetrán, celulares de 10 dígitos y correos del dominio de la finca).
  3. Paso 3 Verificación del XML: se abre directamente con Chrome/Edge/Firefox. Si está bien formado se muestra coloreado; si hay error, el navegador indica la línea del problema.
  4. Paso 4 Se creó manualmente empleados.json con EXACTAMENTE los mismos 5 registros, dentro de la propiedad "empleados" (array de objetos).
  5. Paso 5 Validación del JSON: se pega el contenido en jsonlint.com y devuelve "Valid JSON" sin errores de sintaxis.

4. PARTE C — Aplicación CRUD web en JavaScript (crud.html)

La guía permite realizar la Parte C "en otra herramienta como Python o en web con JavaScript". Se eligió el CRUD web porque no requiere instalar nada: solo abrir crud.html con Chrome, Edge o Firefox.

Cómo se cumple cada requisito

RequisitoImplementación en el código
RF-01 Cargar datos Al abrir la página, cargarDatosIniciales() hace fetch("empleados.json"); si falla lee empleados.xml con DOMParser. Además restaura cambios previos guardados en localStorage si existen.
RF-02 Visualizar renderizarTabla() pinta la tabla de 7 columnas con encabezados descriptivos y filas alternadas; esc() evita que los datos rompan el HTML.
RF-03 Agregar Campos TextBox del formulario + botón Guardar: guardarEmpleado() agrega el registro al array y lo persiste.
RF-04 Editar seleccionarFila(id) (un clic en la fila o doble clic) carga los 7 datos en los TextBox; al guardar, el índice indiceEditando indica que es una actualización, no un nuevo registro.
RF-05 Eliminar eliminarEmpleado(id) pide confirmación con confirm() antes de remover del array y del archivo.
RF-06 Guardar archivo persistir() guarda copia en localStorage y el botón "Descargar XML y JSON" genera los dos archivos actualizados con generarXml() y generarJson() para reemplazar los de la Parte B.
RF-07 Validación guardarEmpleado() valida nombre/documento/email vacíos, formato del correo (regex) y documentos duplicados; muestra mensaje informativo con mostrarMensaje().
RF-08 ID automático calcularIdSiguiente() obtiene el máximo IdEmpleado + 1; el usuario nunca escribe el ID (el campo txtId es de solo lectura).

Cómo explicar la lógica al profesor

  • Modelo en memoria: el array empleados es la "Lista de empleados". Toda la interfaz se dibuja a partir de él (renderizarTabla()), como un grid que se refresca.
  • Ciclo de una operación: modificar el array → persistir() → renderizarTabla(). Un solo camino para agregar, editar o eliminar: por eso los datos del grid y del archivo nunca se desincronizan.
  • Doble persistencia: los mismos datos se generan en XML y JSON; el XML para verificarlo en el navegador y el JSON para validarlo en jsonlint.com.

5. PARTE C — Proyecto equivalente en C# Windows Forms (AppCSharp)

Además de la versión web se creó el proyecto clásico de la guía para que puedas compilarlo en Visual Studio 2022 Community (o ejecutarlo con .NET 8):

Qué hace cada archivo

ArchivoResponsabilidad
CrudOroVerde.csproj Declara el proyecto: aplicación WinExe con net8.0-windows y UseWindowsForms=true.
Program.cs Main: inicializa la aplicación y abre el formulario principal Principal.
Empleado.cs Clase entidad con los 7 campos exactos de la estructura. La propiedad extra IngresoTexto da la fecha formateada para el grid.
Principal.cs Lógica CRUD: carga XML/JSON ( XmlSerializer y JsonSerializer), refresca el DataGridView (DataSource), valida campos (RF-07), genera IDs (Max + 1), guarda en ambos formatos y exporta CSV.
Principal.Designer.cs Construye la interfaz: dgvEmpleados con 7 columnas de encabezados descriptivos, TextBoxes txtId … txtEmail, dtmIngreso, botones btnNuevo, btnGuardar, btnEliminar, btnLimpiar, btnExportarCsv, buscador txtBuscar y etiquetas de estado. Los nombres siguen notación húngara/camelCase como pide la guía.

Cómo compilarlo y mostrarlo

  1. Paso 1 Abre Visual Studio 2022 → "Abrir un proyecto o solución" → selecciona AppCSharp/CrudOroVerde.csproj. (Requiere la carga "Escritorio .NET"; con .NET 8 instalado compila directo).
  2. Paso 2 Presiona F5 (o el botón Iniciar). El formulario carga empleados.xml o empleados.json y pinta el DataGridView (RF-01).
  3. Paso 3 Flujo para demo con el profesor: Nuevo → llenar campos → Guardar (RF-03) · clic en una fila → editar → Guardar (RF-04) · seleccionar fila → Eliminar y confirmar (RF-05) · Verificar que empleados.xml y empleados.json se actualizaron (RF-06).
  4. Paso 4 Nota: guarda los archivos empleados.xml y empleados.json en la carpeta del proyecto (la aplicación los busca en la carpeta padre Oro verde finca la sonora).

6. Puntos extra implementados (bonus)

  • 🔍 Búsqueda / filtro de empleados en vivo por nombre, documento o correo, tanto en la versión web como en el formulario C#.
  • ⬇ Exportar a CSV con separador ';' (compatible con Excel).
  • 🔄 Soporte dual XML+JSON simultáneo: toda operación se persiste en los dos formatos; en la interfaz hay selector de formato preferido y botón de descarga de ambos archivos.
  • 💾 Copias en localStorage (web): los cambios sobreviven al recargar la página aunque el archivo de disco no se reemplace.
  • 🛡 Extra de validaciones: correo con formato válido, documento no duplicado y campo de ID siempre de solo lectura.

7. Cómo entregar y verificar (resumen para el profesor)

  1. Parte B Abrir empleados.xml en el navegador (debe verse coloreado) y pegar empleados.json en jsonlint.com (debe devolver "Valid JSON"). Ambos contienen los mismos 5 empleados.
  2. Parte C web Abrir crud.html y demostrar el flujo completo: cargar (automático al iniciar) → agregar → editar → eliminar con confirmación → Descargar XML y JSON para dejar los archivos consistentes.
  3. Parte C C# Abrir AppCSharp/CrudOroVerde.csproj en Visual Studio 2022 y ejecutar con F5 para mostrar el mismo CRUD en el DataGridView.
  4. Bonus Mostrar el filtro de búsqueda escribiendo en la caja, la exportación CSV y el selector dual XML/JSON.
